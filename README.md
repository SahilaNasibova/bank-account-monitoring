# Bank Account Monitoring & Balance Analysis

**Oracle SQL | PL/SQL | Banking Data Analytics**

## Project Overview

This project focuses on bank account monitoring, account balance analysis, and financial reporting using Oracle SQL and PL/SQL.

It includes database functions and procedures for identifying blocked accounts, analyzing account balances, and processing daily account information.

## Key Components

### 1. Blocked Account Monitoring
- Identification of blocked and non-blocked accounts
- Account status classification
- Customer-level account analysis
- Date-based filtering of account restrictions

### 2. Account Balance Analysis
- Average account balance calculations
- Account classification by customer type
- Current and deposit account analysis
- Balance reporting in AZN and foreign currencies

### 3. Daily Account Reporting
- Processing daily account balance records
- Customer and branch segmentation
- Account categorization
- Automated data insertion into reporting tables

## Technical Skills

- Oracle SQL and PL/SQL
- Stored Functions and Procedures
- Pipelined Table Functions
- Common Table Expressions (CTEs)
- INNER JOIN and LEFT JOIN
- INTERSECT
- CASE Expressions
- Aggregate Functions
- Data Filtering and Transformation
- Financial Reporting
